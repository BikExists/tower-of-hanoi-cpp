hanoi_explicit_stack.cpp (How OS handles recursion) 
#include <iostream>
#include <stack>
using namespace std;

struct StackFrame {
    int n;
    char from_rod, to_rod, aux_rod;
    int stage; // 0: start subproblem 1, 1: after subproblem 1, 2: after subproblem 2
};

void towerOfHanoiIterative(int n, char from, char to, char aux) {
    stack<StackFrame> st;
    st.push({n, from, to, aux, 0});

    while (!st.empty()) {
        StackFrame &curr = st.top();

        if (curr.n == 1) {
            cout << "Move disk 1 from " << curr.from_rod << " to " << curr.to_rod << endl;
            st.pop();
            continue;
        }

        if (curr.stage == 0) {
            curr.stage = 1;
            st.push({curr.n - 1, curr.from_rod, curr.aux_rod, curr.to_rod, 0});
        } else if (curr.stage == 1) {
            cout << "Move disk " << curr.n << " from " << curr.from_rod << " to " << curr.to_rod << endl;
            curr.stage = 2;
            st.push({curr.n - 1, curr.aux_rod, curr.to_rod, curr.from_rod, 0});
        } else {
            st.pop();
        }
    }
}

hanoi_bitwise.cpp (O(1) extra space formula) 
#include <iostream>
using namespace std;

void explainBitwisePattern(int n) {
    long long totalMoves = (1LL << n) - 1; // 2^n - 1 using bitshift

    for (long long k = 1; k <= totalMoves; ++k) {
        // The disk to move at step k is determined by the lowest set bit in k!
        int diskToMove = __builtin_ffs(k); // 1-based index of lowest set bit
        
        // Odd steps always move disk 1. Even steps move other disks.
        cout << "Step " << k << ": Move disk " << diskToMove << endl;
    }
}
🔥 Competitive Programming Trick: At step k, the disk moved is exactly 1 + number of trailing zeros in k. Disk 1 moves every 2 steps (at odd numbers: 1, 3, 5, 7...).

04. Mathematical Analysis & University Exam Proofs

Step-by-step recurrence expansion, mathematical induction, and space-time complexity.

Method 1

Repeated Substitution (Iteration Method)

Let $T(n)$ be the time (number of moves) to solve for $n$ disks:

$$T(n) = 2T(n-1) + 1 \quad \text{--- (Eq. 1)}$$

Substitute $T(n-1) = 2T(n-2) + 1$ into (Eq. 1):

$$T(n) = 2[2T(n-2) + 1] + 1 = 4T(n-2) + 2 + 1$$ $$T(n) = 2^2 T(n-2) + (2^1 + 2^0)$$

Substitute $T(n-2) = 2T(n-3) + 1$:

$$T(n) = 2^3 T(n-3) + (2^2 + 2^1 + 2^0)$$

Continuing this pattern for $k$ steps:

$$T(n) = 2^k T(n-k) + \sum_{i=0}^{k-1} 2^i$$

Base condition occurs when $n - k = 1 \implies k = n - 1$ and $T(1) = 1$:

$$T(n) = 2^{n-1} T(1) + \sum_{i=0}^{n-2} 2^i = \sum_{i=0}^{n-1} 2^i = \frac{2^n - 1}{2 - 1} = \mathbf{2^n - 1}$$

Hence, Time Complexity is $\mathbf{\Theta(2^n)}$ or $\mathbf{O(2^n)}$.

Method 2

Proof by Mathematical Induction

Proposition $P(n)$: The minimum number of moves to transfer $n$ disks is $M(n) = 2^n - 1$.

Step 1: Base Case (n = 1)

For $n = 1$, we move the single disk directly from Source to Destination: $M(1) = 1$.

Formula check: $2^1 - 1 = 2 - 1 = 1$. True for $n = 1$.

Step 2: Induction Hypothesis

Assume $P(k)$ is true for some positive integer $k$. That is:

$$M(k) = 2^k - 1$$
Step 3: Inductive Step (Prove for n = k + 1)

To transfer $(k + 1)$ disks:

  1. Move top $k$ disks from Source to Auxiliary: takes $M(k)$ moves.
  2. Move largest $(k+1)$-th disk to Destination: takes $1$ move.
  3. Move $k$ disks from Auxiliary to Destination: takes $M(k)$ moves.
$$M(k+1) = M(k) + 1 + M(k) = 2M(k) + 1$$ $$= 2(2^k - 1) + 1 = 2^{k+1} - 2 + 1 = \mathbf{2^{k+1} - 1}$$

Therefore, by the principle of mathematical induction, $P(n)$ holds $\forall n \ge 1$. Q.E.D.

🧠 Why is Space Complexity O(n)?

A very common 2nd-year exam confusion is: "If total function calls are $2^{n+1}-1$, why isn't space complexity $O(2^n)$?"

  • Space complexity in recursion is determined by the maximum call stack depth at any single instant, NOT the total calls made over time.
  • Since the algorithm follows Depth-First Search (DFS) traversal down the tree, each branch completes and pops its stack frames before the next branch begins.
  • The maximum depth of the recursion tree is exactly $n$. Hence auxiliary space is $O(n)$.
